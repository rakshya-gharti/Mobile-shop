2. Setup & configuration

  1. Install Visual Studio 2019/2022 (ASP.NET workload) - this includes SQL Server Express LocalDB.
  2. Choose File > Open > Web Site and select this folder (MobileShop).
  3. Press Ctrl+F5. On first run Global.asax automatically creates App_Data\ShopDB.mdf and runs App_Data\Schema.sql (tables, categories, sample products, test accounts). No manual database setup is required.
  4. The connection string (ShopDB) is stored in Web.config and uses AttachDbFilename=|DataDirectory|\ShopDB.mdf. If you use SQL Server Express instead of LocalDB, change Data Source to .\SQLEXPRESS.
  5. Email: messages are written as .eml files to C:\Temp\GlowUpMail (create this folder, or edit mailSettings in Web.config). Every email is also stored as an in-app notification on the Orders page.
  6. To test on a phone, use the browser's device toolbar (F12) or browse to the PC's IP address.

3. Page map

  • Public: Default (catalog, search, sort), ProductDetail, Register, Login, Feedback, Error
  • Member only (Member/): Cart (current), Checkout (payment + email), Orders (history, tracking, cancel), Rate (ratings), Profile, Wishlist
  • Admin only (Admin/): Default (dashboard, low-stock, sales, feedback), Products (CRUD), Categories (CRUD), Orders (Pending / Delivery / Delivered / Cancelled), Users (RUD)

4. Quick walkthrough

  1. Browse the catalog as a guest, then Register or login as member.
  2. Add products to the cart (or save to wishlist), apply WELCOME10, and Checkout.
  3. Login as admin: open Manage Orders, press Ship then Mark delivered.
  4. Login again as the member: open Orders and press Rate on a delivered item.

5. Extra features

Wishlist, reward points and member badges, discount coupons, low-stock alerts, related-product recommendations, in-app notifications, auto-rotating promo banner, admin sales dashboard.
